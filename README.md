# Web Development Practice

A hands-on learning journal in HTML, CSS and vanilla JavaScript. It contains multiple small projects and four graded practice sets, all linked from one landing site. There are no frameworks and no build step. Everything runs by opening a file in the browser.

## What's inside

```text
web-dev-practice/
├── index.html, style.css, script.js   # Landing site
├── digital-clock/                     # Live clock + New Year countdown
├── image-gallery/                     # Image gallery with lightbox
├── portfolio/                         # Personal portfolio page
├── Weather-App/                       # Weather application
├── Student-Management-Dashboard/      # Student management + analytics
├── practice_set1/                     # HTML fundamentals
├── practice_set2/                     # CSS fundamentals
├── practice_set3/                     # JavaScript basics
└── practice_Set4/                     # localStorage, fetch, validation, ES6

## Projects

## Projects

| Project | What it does | Key concepts |
|---|---|---|
| **Digital Clock** | Shows the current time and a live New Year countdown. | `Date`, `setInterval`, JavaScript |
| **Image Gallery** | Displays images in a grid with a lightbox view. | DOM events, CSS Flexbox/Grid |
| **Portfolio** | Personal portfolio containing about, education, skills, projects and contact sections. | HTML, CSS, JavaScript |
| **Weather App** | Searches for a city and displays weather information. | `fetch`, `async/await`, REST APIs, `localStorage` |
| **Student Management Dashboard** | Add, edit, delete, search and filter student records with analytics. | CRUD, forms, validation, `localStorage` |

## Practice Sets

| Set | Focus | Exercises |
|---|---|---|
| **Set 1** | HTML | Web page, student marks table, registration form and multi-page website |
| **Set 2** | CSS | Backgrounds, fonts, Flexbox, CSS Grid and hover effects |
| **Set 3** | JavaScript Basics | Even/odd checker, colour changer, calculator and today's date |
| **Set 4** | Browser APIs and ES6 | `localStorage`, `fetch`, email validation and arrow functions |

## Student Management Dashboard

The Student Management Dashboard allows users to:

- Add student records
- Edit student details
- Delete students
- Search students
- Filter by department
- Filter by semester
- Validate CGPA
- Store student data using `localStorage`
- View student analytics
